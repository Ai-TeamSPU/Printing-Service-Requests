# เชื่อมต่อ Google Sheet + Google Drive จริง (Google Apps Script)

เว็บ Printing-Service-Requests เป็นเว็บ static (ไม่มีเซิร์ฟเวอร์ของตัวเอง) วิธีที่ง่ายและปลอดภัยพอสำหรับงานภายในองค์กรคือให้ **Google Apps Script** ทำหน้าที่เป็น backend ตัวกลาง — สคริปต์นี้จะรันด้วยบัญชี Google ของคุณ อ่าน/เขียน Sheet และ Drive แทนหน้าเว็บ โดยหน้าเว็บจะยิง request ไปที่ URL ของสคริปต์เท่านั้น ไม่ได้แตะ Sheet/Drive โดยตรง

> **อัปเดตล่าสุด:** เพิ่มคอลัมน์ `budget_source` และ `budget_acct` ต่อท้ายแท็บ `JOBS` (ใช้คำนวณ "สรุปรายได้" ในเอกสารสรุปรายงานจากแหล่งงบประมาณจริงที่ผู้ขอเลือก แทนสัดส่วนสมมติ) — ถ้าตั้งค่าไว้แล้วก่อนหน้านี้ ต้อง **วางโค้ด `Code.gs` เวอร์ชันใหม่ทับของเดิม แล้วรัน `setupSheets` อีกครั้ง** เพื่อเพิ่ม 2 คอลัมน์นี้ให้ชีตที่มีอยู่ (ข้อมูลแถวเดิมจะไม่หายหรือถูกแก้ไข) จากนั้น Deploy เวอร์ชันใหม่ตามขั้นตอนที่ 7
>
> **อัปเดตอีกรอบ:** ปุ่ม "ส่งอีเมล" ในหน้า "เอกสารสรุปรายงาน" ตอนนี้ส่งอีเมลจริงผ่าน `MailApp` แล้ว (ต้องกรอกอีเมลปลายทางในกล่องที่เด้งขึ้นมาทุกครั้งก่อนส่ง ไม่มีอีเมลตายตัว) — วางโค้ด `Code.gs` เวอร์ชันใหม่ทับแล้ว **Deploy เวอร์ชันใหม่** ตามขั้นตอนที่ 7 อีกครั้ง ไม่ต้องรัน `setupSheets` เพิ่มสำหรับส่วนนี้ (ไม่มีการเพิ่มคอลัมน์) แต่ครั้งแรกที่กดส่งอีเมลอาจมีป๊อปอัปขอสิทธิ์ "ส่งอีเมลในนามของคุณ" (Gmail scope) — ต้องไปกด **Allow** เองในตัวแก้ไข Apps Script ก่อน โดยเลือกฟังก์ชัน `authorizeMailSend` จาก dropdown แล้วกด Run ครั้งเดียว (ดูหัวข้อ "ส่งอีเมลรายงานให้ผู้บริหาร" ด้านล่าง)
>
> **อัปเดตอีกรอบ:** เพิ่มการตรวจจับอีเมลผู้ขอกับ "ทะเบียนบุคลากร" — ตอนกรอกอีเมล @spu.ac.th ที่หน้า gate ("เริ่มใช้บริการ") ระบบจะเทียบกับแท็บ **`Personnel_Information`** ถ้าเจอ จะดึงชื่อ-สกุลและหน่วยงานมาเติมฟอร์มให้อัตโนมัติ — วางโค้ด `Code.gs` เวอร์ชันใหม่ทับแล้ว **Deploy เวอร์ชันใหม่** ตามขั้นตอนที่ 7 จากนั้นดูหัวข้อ "ทะเบียนบุคลากร (Personnel_Information)" ด้านล่างเพื่อสร้างแท็บนี้
>
> **อัปเดตล่าสุด:** แยกคอลัมน์ `variant_snapshot` ในแท็บ `JOB_ITEMS` ออกเป็นคอลัมน์ย่อย `color_mode, paper_size, paper_type, sides, staple, own_paper, qty_original, qty_sets, exam_type, exam_subject` (คอลัมน์ M-V) เพื่อให้เปิดชีตแล้วเห็นรายละเอียดแยกเป็นคอลัมน์ชัดเจน — **เลิกเขียนคอลัมน์ `variant_snapshot` (D) สำหรับงานใหม่แล้ว แต่คอลัมน์เดิมยังอยู่ ไม่ได้ลบ** ข้อความสรุปของงานเก่าที่เคยบันทึกไว้ก่อนหน้านี้จึงไม่หาย — วางโค้ด `Code.gs` เวอร์ชันใหม่ทับ แล้ว **รัน `setupSheets` อีกครั้ง** เพื่อเพิ่มคอลัมน์ M-V ให้ชีตที่มีอยู่ (ข้อมูลเดิมไม่หาย) จากนั้น Deploy เวอร์ชันใหม่ตามขั้นตอนที่ 7

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### 1. สร้าง Google Sheet
สร้างสเปรดชีตเปล่า 1 ไฟล์ ตั้งชื่อ เช่น `SPU-Printing-Service-DB`

### 2. วางสคริปต์
ในสเปรดชีตนั้น เปิด **ส่วนขยาย (Extensions) > Apps Script** แล้วลบโค้ดตัวอย่างเดิมทั้งหมด วางเนื้อหาไฟล์ [`Code.gs`](./Code.gs) ในโฟลเดอร์นี้แทน แล้วบันทึก (Ctrl+S)

### 3. ตั้งรหัสลับเชื่อมต่อ
คลิกไอคอนรูปเฟือง **Project Settings** ทางซ้าย เลื่อนไปที่ **Script properties** กด **Add script property**
- Property: `CONNECT_TOKEN`
- Value: รหัสลับที่คุณตั้งเอง (แนะนำสุ่มยาว ๆ เช่นจาก https://www.uuidgenerator.net) — **เก็บค่านี้ไว้ จะใช้กรอกในหน้าเว็บด้วย**

### 4. สร้างแท็บทั้งหมดอัตโนมัติ
กลับไปที่ตัวแก้ไข เลือกฟังก์ชัน `setupSheets` จาก dropdown ด้านบน แล้วกด **Run** (รูปสามเหลี่ยม ▷)
- ครั้งแรกจะขึ้นขอสิทธิ์ (Authorize) — เลือกบัญชี Google ของคุณ แล้วกด **Advanced > Go to (ชื่อโปรเจกต์) (unsafe) > Allow** (ข้อความ "unsafe" เป็นเรื่องปกติสำหรับสคริปต์ที่คุณเขียนเอง)
- เมื่อรันเสร็จ กลับไปที่สเปรดชีต จะเห็นแท็บ `JOBS, JOB_ITEMS, PRICE_RULES, UNITS, USERS, FILES, STATUS_LOG, NOTIFY_LOG, SETTINGS` พร้อมหัวตารางครบ

### 5. คัดลอก Spreadsheet ID
ดูที่ URL ของสเปรดชีต:
`https://docs.google.com/spreadsheets/d/`**`ตรงนี้คือ Spreadsheet ID`**`/edit`

### 6. สร้างโฟลเดอร์ Drive
สร้างโฟลเดอร์บน Google Drive ชื่อ เช่น `Printing-Service` (แนะนำสร้างเป็น Shared Drive ถ้าองค์กรมีสิทธิ์ใช้ เพื่อไม่ให้ไฟล์ผูกกับบัญชีคนเดียว) คัดลอก Folder ID จาก URL:
`https://drive.google.com/drive/folders/`**`ตรงนี้คือ Folder ID`**

### 7. Deploy เป็น Web App
กลับไปที่ตัวแก้ไข Apps Script กด **Deploy > New deployment**
- ไอคอนรูปเฟือง เลือกประเภท **Web app**
- Execute as: **Me**
- Who has access: **Anyone**
- กด **Deploy** แล้วกด **Authorize access** ถ้ามีขอเพิ่ม
- คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) เก็บไว้

### 8. กรอกในหน้าเว็บ
เปิดหน้าเว็บ ไปที่แท็บ **ตั้งค่าเชื่อมต่อ** แล้วกรอก:
- Web App URL (จากข้อ 7)
- รหัสลับเชื่อมต่อ (จากข้อ 3)
- Spreadsheet ID (จากข้อ 5)
- Drive Folder ID (จากข้อ 6)

กด **ทดสอบการเชื่อมต่อทั้งหมด** — ถ้าขึ้น "สำเร็จ" ทั้ง 3 การ์ด แปลว่าเชื่อมต่อจริงเรียบร้อย

## ทะเบียนบุคลากร (Personnel_Information) — เติมฟอร์มอัตโนมัติตอนกรอกอีเมล

หน้า "เริ่มใช้บริการ" ตอนผู้ขอกรอกอีเมล @spu.ac.th แล้วกด "ขอรับบริการ" ระบบจะเทียบอีเมลนั้นกับแท็บ `Personnel_Information` — ถ้าเจอ จะดึง **ชื่อ-สกุล** และ **หน่วยงาน** มาเติมในฟอร์มให้อัตโนมัติ (ไม่ต้องพิมพ์เอง)

**วิธีตั้งค่า:**
1. ในตัวแก้ไข Apps Script เลือกฟังก์ชัน **`setupPersonnelSheet`** จาก drop down แล้วกด Run — จะสร้างแท็บ `Personnel_Information` เปล่าพร้อมหัวตาราง `requester_email, full_name, unit_name` ให้ (ฟังก์ชันนี้ **จะไม่ทำอะไรเลยถ้าแท็บนี้มีอยู่แล้ว** ปลอดภัยกับข้อมูลเดิมของคุณ ต่อให้หัวตารางของคุณจะตั้งชื่อไม่เหมือนกันก็ตาม)
2. กรอกรายชื่อบุคลากรลงไป: คอลัมน์อีเมล, ชื่อ-สกุล, หน่วยงาน คนละแถว
3. ถ้าคุณมีแท็บนี้อยู่แล้วด้วยหัวตารางเป็นภาษาไทย (เช่น "ชื่อ-สกุล", "หน่วยงาน") ไม่ต้องแก้อะไร — ระบบรองรับหัวตารางได้ทั้งแบบอังกฤษ (`full_name`, `unit_name`, `email`) และแบบไทยอยู่แล้ว
4. ไม่พบอีเมลในทะเบียน หรือยังไม่ได้สร้างแท็บนี้ → ฟอร์มจะว่างให้กรอกเองตามปกติ ไม่มี error ใด ๆ ขึ้นให้ผู้ใช้เห็น

## ส่งอีเมลรายงานให้ผู้บริหาร — อนุมัติสิทธิ์ครั้งแรก

ปุ่ม "ส่งอีเมล" ในหน้า "เอกสารสรุปรายงาน" ต้องขอสิทธิ์ Gmail scope เพิ่มจาก Apps Script ก่อนถึงจะใช้ได้ (ครั้งเดียวพอ):
1. ในตัวแก้ไข Apps Script เลือกฟังก์ชัน **`authorizeMailSend`** จาก dropdown แล้วกด Run
2. จะมีหน้าต่าง "Authorization required" เด้งขึ้น → Review permissions → เลือกบัญชี (ต้องเป็นบัญชีเดียวกับที่ deploy Web App) → Advanced → Go to [ชื่อโปรเจกต์] (unsafe) → Allow
3. เช็คอินบ็อกซ์ของบัญชีนั้น ควรได้รับอีเมลทดสอบ "ทดสอบสิทธิ์ส่งอีเมล — SPU Printing Service"
4. ไม่ต้อง Deploy เวอร์ชันใหม่หลังจากนี้ สิทธิ์ผูกกับโปรเจกต์ ทำครั้งเดียวจบ

## ข้อควรรู้

- **ตอนนี้ใช้เฉพาะ Google Sheet ก็พอ** — หน้า "แบบฟอร์มบริการ" กดส่งคำขอแล้วจะเขียนแถวจริงลงแท็บ `JOBS` และ `JOB_ITEMS` โดยไม่ต้องกรอก Drive Folder ID ก่อนก็ได้ (ถ้ายังไม่กรอก ระบบจะข้ามการสร้างโฟลเดอร์งานบน Drive ไปเฉย ๆ คอลัมน์ `drive_folder_id` จะว่างไว้) การ์ด "Google Drive" ในหน้าตั้งค่ายังอยู่ให้ตั้งค่าเพิ่มทีหลังได้เมื่อพร้อม
- ก่อนกดส่งคำขอจากฟอร์มจริงจะต้องกรอกครบ **3 อย่าง** ในหน้าตั้งค่า: Web App URL, รหัสลับ (Token), Spreadsheet ID — ไม่ต้องมี Folder ID ก็ส่งได้
- ข้อมูลที่กรอกในหน้าเว็บ (URL, token, Spreadsheet ID, Folder ID) **บันทึกไว้ในเบราว์เซอร์ (localStorage) ของเครื่องนั้น ๆ เท่านั้น** — เปิดเว็บจากเครื่อง/เบราว์เซอร์อื่นต้องกรอกใหม่ ถ้าต้องการให้ทุกคนใช้ค่าเดียวกันโดยไม่ต้องกรอกเอง ให้ฝัง URL/Spreadsheet ID เป็นค่าเริ่มต้นในโค้ด (แจ้งได้ ผมช่วยแก้ให้)
- **หน้าคิวงาน / งานของฉัน / แดชบอร์ด / ติดตามสถานะ / ข้อมูลการคำขอรับบริการ** ดึงข้อมูลจริงจาก Google Sheet ทั้งหมดแล้ว (ไม่มีข้อมูลตัวอย่าง/mock ปนอยู่อีกต่อไป) — ถ้ายังไม่ได้ตั้งค่าเชื่อมต่อ หน้าต่าง ๆ จะแสดง "ไม่มีข้อมูล" แทนที่จะมีตัวอย่างให้ดูเฉย ๆ
- อย่าตั้ง "Who has access" เป็นอย่างอื่นนอกจาก "Anyone" มิฉะนั้นเบราว์เซอร์ของผู้ใช้ทั่วไปจะเรียกสคริปต์ไม่ได้ (ความปลอดภัยมาจากรหัสลับ `CONNECT_TOKEN` แทน ไม่ใช่จากการจำกัดผู้เรียก)
- ถ้าแก้โค้ดใน `Code.gs` ภายหลัง ต้องทำ **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** ใหม่ทุกครั้ง ไม่งั้น URL เดิมจะยังรันโค้ดเวอร์ชันเก่าอยู่
